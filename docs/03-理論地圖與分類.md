## 一、六大理論分類

《派對咖孔明》相關分析所動用的理論，可以收斂成六大類。每一類都有自己的「大師」（理論原創者）與原典出處。

### A. 創業決策理論（效果邏輯家族）→ 詳見 [04-效果邏輯深論](04-效果邏輯深論.md)

整套分析中最核心、與作品貼合度最高的一類。回答的問題是：**在沒人知道會不會成功的情況下，該怎麼做決定？**

| 理論 | 大師 / 原典 | 一句話 |
|------|------------|--------|
| 效果邏輯 vs 因果邏輯 | Saras Sarasvathy（2001, *AMR*） | 因果邏輯先定目標再找資源；效果邏輯先盤點資源再長出目標 |
| 手中鳥原則 | Sarasvathy | 從「我是誰、我會什麼、我認識誰」出發 |
| 可承受損失原則 | Sarasvathy | 先問「輸得起嗎」，不問「能賺多少」 |
| 拼布原則 | Sarasvathy | 把遇到的人織成夥伴網，而不是做競爭分析 |
| 檸檬水原則 | Sarasvathy | 把意外與壞事榨成新機會 |
| 飛行員原則 | Sarasvathy（原則見 2001 論文；助記名稱 2008 後定型） | 控制可控之事，未來是做出來的，不是預測出來的 |
| 奈特不確定性 | Frank Knight（1921） | 「風險」算得出機率，「不確定性」連機率都沒有 |
| 創業拼裝（bricolage） | Baker & Nelson（2005, *ASQ*） | 用手邊現成的東西湊出新解法 |
| 組織即興 | Moorman & Miner（1998, *AMR*） | 變化快到來不及規劃時，邊做邊組構回應 |
| 利害關係人理論 | R. Edward Freeman（1984） | 事業是由所有「押了真承諾的人」共同定義的 |

### B. 行銷理論 → 詳見 [05-行銷理論深論](05-行銷理論深論.md)

回答的問題是：**怎麼讓對的人注意到你、記住你、選擇你？**

| 理論 | 大師 / 原典 | 一句話 |
|------|------------|--------|
| STP | Wendell Smith（1956）奠基，Kotler 體系化 | 先切市場、再選客群、最後佔領心智位置 |
| 4P / 7P | McCarthy（1960）；Booms & Bitner（1981） | 產品、價格、通路、推廣（服務業加人員、流程、實體證據） |
| AIDA / 行銷漏斗 | 通說歸 E. St. Elmo Lewis（1898 前後） | 注意 → 興趣 → 慾望 → 行動 |
| 藍海策略 | Kim & Mauborgne（2004/2005） | 不在紅海硬拚，用價值創新開新戰場 |
| 游擊行銷 | Jay Conrad Levinson（1984） | 小預算靠創意與奇襲取勝 |
| 病毒式行銷 / 流量挪用 | 詞源通說 Steve Jurvetson（1997） | 讓使用者替你傳播；把別人的流量導成自己的 |
| Gruen 效應 | 得名自建築師 Victor Gruen | 動線讓人迷失方向、延長停留、誘發非計劃行為 |
| 價值主張／商業模式畫布 | Osterwalder & Pigneur（2010/2014） | 用一張圖對齊「顧客要什麼」與「我們給什麼」 |

### C. 競爭與策略理論 → 詳見 [06-策略與競爭理論深論](06-策略與競爭理論深論.md)

回答的問題是：**產業的錢往哪裡流？弱者要怎麼跟強者打？**

| 理論 | 大師 / 原典 | 一句話 |
|------|------------|--------|
| 五力分析 | Michael Porter（1979 HBR / 1980） | 產業獲利被五種力量瓜分：對手、新進者、買方、供應商、替代品 |
| 通用競爭戰略 | Porter（1980） | 成本領先、差異化、集中——別卡在中間 |
| 資源基礎觀點 RBV | Jay Barney（1991） | 持續優勢來自有價值、稀有、難模仿、難替代的資源組合 |
| 破壞式創新 | Clayton Christensen（1995/1997） | 從巨頭看不上的邊緣市場切入，最後顛覆主流 |
| 柔道戰略 | Yoffie & Cusumano（1999 HBR）；專書為 Yoffie & Kwak（2001） | 借對手的體重與慣性摔倒對手 |
| 賽局理論 | von Neumann & Morgenstern（1944）、Nash | 我的最佳選擇取決於對手怎麼想我會怎麼選 |
| Product-Market Fit | Andy Rachleff 創詞、Andreessen（2007）普及 | 產品做出市場真正想要的東西之前，其他都不重要 |
| 網路效應 | Katz & Shapiro（1985）、Metcalfe | 用的人越多，產品對每個人的價值越高 |
| SWOT | 起源有爭議（詳查證報告） | 優勢、劣勢、機會、威脅的盤點框架 |
| OKR | Andy Grove 創、John Doerr 推廣 | 一個振奮人心的目標配上可量測的關鍵結果 |

### D. 組織、領導與人資 → 詳見 [07-組織領導與行為經濟深論](07-組織領導與行為經濟深論.md)

回答的問題是：**怎麼找到人、留住人、讓團隊敢冒險？**

| 理論 | 大師 / 原典 | 一句話 |
|------|------------|--------|
| 心理安全 | Amy Edmondson（1999, *ASQ*） | 團隊敢說真話、敢犯錯，才學得快 |
| 雇主品牌 / EVP | Ambler & Barrow（1996） | 公司對人才也是一個「品牌」，賣的是願景與體驗 |

## 三、一條貫穿全部的鐵律

> **計謀只是入口，產品力才是留存。**

孔明所有的計，只負責把人「帶進門」（搶注意力）；讓人留下來的，永遠是英子的歌聲（產品本身）。這條鐵律同時是：

- 行銷漏斗的教訓（流量 ≠ 留存）
- 效果邏輯飛行員原則的體現（把資源押在自己可控、可累積的核心資產上）
- 對所有想「學孔明用計」的人的警告：**門裡沒有真貨，人轉頭就走。**
