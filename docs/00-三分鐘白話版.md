# 三分鐘白話版：完全沒讀過商管書也能懂

> 這一頁不用任何術語。想深入的時候，再去讀後面的章節就好。

## 這是一部什麼漫畫？

三國時代最聰明的軍師**諸葛孔明**，死後轉生到現代東京澀谷——正好是萬聖節，滿街變裝，沒人發現他是真貨。他在夜店遇到一個唱歌很好聽、卻紅不起來的女生**月見英子**，被她的歌聲感動，決定用兩千年前打仗的頭腦，幫她在音樂圈「打天下」。

聽起來很鬧，對吧？但全世界的商學院愛好者都在傳這部漫畫，日本講談社甚至出了一本官方商業書《孔明に訊け！》（去問孔明！）。為什麼？

**因為孔明每一次出手，都剛好是一堂商業課。**

## 孔明做了什麼？五個故事

**故事一：迷宮夜店（石兵八陣）**
大牌歌手 Mia 假好心邀英子同一時間、不同舞台演出——想拿她當墊背。孔明不抗議，他改造了整間店：燈光、煙霧、走道全部重新設計，讓來看 Mia 的客人「迷路」走進英子的場子，一聽就走不了。
👉 **白話重點**：IKEA 讓你在賣場繞來繞去多買東西，是同一招。吸引人的第一步不是喊得大聲，是設計「讓人自然走到你面前」的路。

**故事二：最爛的攤位（無中生有）**
音樂祭把英子分到最偏僻的角落，對面還是人氣樂團。孔明放出「我們器材壞了」的假消息讓對手鬆懈，再看準對方主唱嗓子有傷、隔天還有演出不敢唱太兇的空檔，讓英子突然開唱，把全場人吸過來。
👉 **白話重點**：位置爛不是死刑。資源少的人打不起正面戰，就要找對手「不方便出全力」的時刻。

**故事三：請不動的高手（rap battle）**
天才饒舌歌手 KABE 太人得過三次冠軍，卻因為壓力大到胃潰瘍而退隱。孔明沒有捧著錢去挖角——他直接下戰帖跟人家尬饒舌。孔明**輸了**，但 KABE 在過程中想起自己有多愛音樂，自願加入。
👉 **白話重點**：留住厲害的人，靠的不是薪水，是讓他重新找到「為什麼做這件事」。

**故事四：借對手的錢打廣告（草船借箭）**
對手樂團砸一百萬日圓辦「掃 QR code 按讚抽獎」衝人氣。孔明的回應：在同一地點，讓英子他們**假扮對手先開唱**，放出自己的 QR code——對手花錢聚來的人潮，讚全按到英子頭上。
👉 **白話重點**：三國的孔明用草船借了曹操十萬支箭；現代的孔明用假 QR code 借了對手十萬個讚。別人花大錢造出來的聲勢，有時候可以借。

**故事五：真正的決勝點（DREAMER）**
但注意——借來的讚只衝到七萬就被識破了。最後真正突破十萬的，是英子唱出自己寫的歌〈DREAMER〉，把現場所有人（包括對手樂團）都唱哭了。孔明事後還把對手「真實演唱」的影片傳上網，把借來的讚**還了回去**——順便救了對手的職業生涯，化敵為友。

## 整部漫畫最重要的一句話

> **計謀只能把人騙進門，讓人留下來的永遠是「東西本身好不好」。**

孔明所有的計，都只是讓更多人「聽到英子的歌」；如果歌不好聽，一切都白費。做生意、做內容、做產品都一樣：行銷是入口，實力才是留存。門裡沒有真貨，人轉頭就走。

## 為什麼商學院的人特別愛這部？

因為孔明的做事方法，剛好跟一位創業學大師 **Sarasvathy** 研究出來的「高手創業家思考法」一模一樣。她訪問了 27 位超成功的創業家，發現他們跟一般人想的相反——

一般人以為創業要：先寫計畫書 → 做市場調查 → 募資金 → 執行。
高手實際上是：**看看手上有什麼，直接開始做。**

她用「做菜」比喻：
- 一般邏輯＝先決定菜單，再出門買齊食材（萬一買不到就卡死）
- 高手邏輯＝**打開冰箱看有什麼，就地做出一桌菜**

孔明就是後者。他轉生時身無分文，手上只有三樣東西：自己的兵法腦袋、英子的歌喉、夜店老闆這個朋友。他沒有等到「資源到位」才開始——他用這三樣東西直接開局，一路把遇到的每個人、每個意外（甚至每個敵人）都變成自己的資源。

高手的五個習慣，孔明全中：

1. **從手上有的開始**，不等完美條件
2. **先想「最多輸多少」**，不賭「可能賺多少」——孔明每一計失敗了都傷不了筋骨
3. **把對手變隊友**，不執著打倒誰——KABE、對手樂團、甚至大反派最後都被他收編或拯救
4. **把壞事榨成檸檬汁**——爛攤位變奇襲陣地、對手的抽獎變自己的流量
5. **控制自己控制得了的事**，不浪費力氣預測未來——他押注的是「英子的歌會越練越好」這件確定的事

## 三個你明天就能用的心法

1. **開冰箱，別寫菜單**：想做什麼新嘗試，先列出「我是誰、我會什麼、我認識誰」，用現有的東西拼出第一步，而不是等存夠錢、學完課、找到完美夥伴。
2. **先問輸得起嗎**：每個決定先想最壞情況——輸得起就快做，輸不起就縮小規模再試。
3. **把敵人當資源看**：遇到打壓或惡性競爭，先別急著生氣，問一句「他造出來的這個局勢，有沒有我能借力的地方？」

## 一個誠實的提醒

- 這是**漫畫**，孔明開了「神機妙算」的外掛，現實中沒人能像他一樣算無遺策——但正因為我們沒有劇本，「不靠預測、靠手上資源和行動」的思考法才更值得學。
- 孔明有些招數是**騙人的**（假故障、假 QR code）。故事裡很爽，現實中會出事。學他「用手邊資源、化敵為友、化危機為轉機」，不要學他「兵不厭詐」。
