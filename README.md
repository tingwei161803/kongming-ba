# kongming-ba：《派對咖孔明》章節分析知識庫

用商管理論解讀漫畫《派對咖孔明》（パリピ孔明 / Ya Boy Kongming!）——把孔明的每一計拆成「三國典故考證 × 漫畫章節 × 現代管理學說」，所有事實與理論出處均經多 agent 交叉查證並附參考連結。

## 這個庫的三個原則

1. **每個事實都有 reference**：劇情事實對到講談社／Comic DAYS／日文維基等官方來源；理論對到原始論文（含 DOI 與頁碼）。
2. **大師的學說講清楚**：每個被引用的理論都交代原創者、原典、核心主張、限制與學術批評——不只丟名詞。
3. **誠實區分三種內容**：查證過的事實／有先行文獻的對照／本庫的詮釋推演，三者分開標示。

## 查證方式

原始素材為 `tmp/` 內的多份分析報告（**不入版控**，見 `.gitignore`）。整編時以 10 個平行的 Claude Opus 查證 agent 對 140 條敘述逐條核實：114 條確認、22 條部分正確（已修正）、4 條無法查證（已標註）、0 條完全錯誤。詳見 [docs/08-查證報告](docs/08-查證報告.md)。

## 版本注意

《派對咖孔明》有漫畫（2019–）、TV 動畫（2022，P.A.WORKS，12 集）、真人日劇（2023，富士）、真人電影（2025，松竹）四個版本，**同一段劇情的「話數／集數」各不相同**。本庫一律標明「漫畫第 X 話」或「動畫第 X 集」。
