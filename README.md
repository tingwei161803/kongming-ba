# Kongming Codex｜派對咖孔明知識庫

> 三國兵法 × 現代商管理論——把漫畫《派對咖孔明》的每一計解碼成可查證的商業課。

這是一個雙語（英文／繁中）的靜態知識庫網站：整理漫畫《派對咖孔明》（パリピ孔明 / *Ya Boy Kongming!*）中的計謀、劇情事實與其對應的商管理論。所有內容經過多輪交叉查證——140 條敘述逐條比對一手來源（學術論文原文、講談社官方頁、古籍資料庫），114 條確認、22 條修正、4 條標註待考、0 條全錯。

## ✨ 功能特色

- 🌏 **雙語全頁切換** — English / 繁體中文一鍵切換，預設英文
- 🌗 **深色 / 淺色模式** — 「墨與朱印」編輯風設計，兩種主題各自調校
- 📖 **11 個主題頁** — 白話導讀、作品檔案、計謀對照、理論地圖、四份理論深論、查證報告
- 🔍 **即時搜尋＋分類篩選** — 計謀依典故類型、理論依學門、查證依領域
- 🎮 **互動練功房** — 隨堂測驗、字卡翻卡、術語速查、計謀×理論配對遊戲
- 🔗 **深連結** — 每張卡片都有專屬 `#slug` 可直接分享
- 📱 **響應式** — 手機、平板、桌機皆適配
- ⚡ **純靜態零依賴** — 無後端、無 build、載入快

## 📂 內容結構 / 資料來源

網站內容整理自本 repo `docs/` 目錄下的知識庫文件（含完整參考連結與逐條查證表），再前端化為雙語資料層：

```
kongming-ba/
├── index.html          # 首頁（hub）
├── *.html              # 各主題頁（primer / world / stratagems / theories / …）
├── assets/             # styles.css（設計系統）、shell.js（共用外框）、app.js（版型引擎）
├── data/data.js        # 全站雙語內容（唯一資料檔）
└── docs/               # 知識庫原始文件（Markdown，含查證報告與所有參考連結）
```

主要事實來源：日文維基百科「パリピ孔明」條目、講談社作品頁與 Comic DAYS 官方章節頁、動畫官網、松竹電影官網、東立出版社，理論部分為各原始論文（含 DOI 與頁碼，見 `docs/08-查證報告.md`）。

> ⚠️ **非官方**：本站為個人整理之非官方粉絲資源，與講談社、原作者無關；劇情與數字如有出入請以官方出版品為準。理論對照中「有先行文獻」與「本站推演」已分別標註。

## 🛠 本機使用

```bash
# 1. clone 專案
git clone https://github.com/tingwei161803/kongming-ba.git
cd kongming-ba

# 2a. 最簡單：直接開啟 index.html
open index.html

# 2b. 或啟動本機伺服器（建議）
uv run python -m http.server 4173
# 然後瀏覽 http://localhost:4173
```
